# Portfolio CV - Lục Mạnh Tôn

Website portfolio cá nhân giới thiệu Lục Mạnh Tôn với vai trò Frontend Developer. Trang được thiết kế theo tư duy mobile-first, sử dụng HTML5 ngữ nghĩa và CSS3 (Flexbox + Grid), tối ưu trải nghiệm trên mọi kích thước màn hình.

## Điểm nổi bật

- Giao diện sạch, hiện đại với hệ màu teal + amber.
- Hỗ trợ dark mode tự động theo hệ thống.
- Typography fluid với `clamp()`.
- Sticky header với backdrop blur.
- Hover micro-interactions trên thẻ dự án và skill chips.
- Khả năng tiếp cận tốt: focus-visible, reduced motion, alt text đầy đủ.
- Responsive hoàn hảo: 1 → 2 → 3 cột cho lưới dự án.

## Chức năng

- Điều hướng nội trang mượt mà.
- Hiển thị giới thiệu, kỹ năng, dự án tiêu biểu.
- Form liên hệ (giao diện).
- Nút quay lại đầu trang.

## Công nghệ

- HTML5
- CSS3 (Custom Properties, Flexbox, Grid, Media Queries)
- Responsive design mobile-first
